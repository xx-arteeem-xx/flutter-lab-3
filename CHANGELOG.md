## [1.0.0] — 2026-05-22

### Добавлено

#### Ядро и инфраструктура
- Инициализирован Flutter-проект `flutter_lab_3` (Android, Dart 3.3+, Flutter 3.24)
- EAM Design System: скопированы цветовые константы из `flatter-lab-2` (`AppColors`) — тёмный фон `#080A11`, акцент `#50C8FF` (dark) / `#173EAC` (light)
- Шрифт Nunito через `google_fonts ^6.2.1` — полный `ThemeData` для тёмной и светлой тем (`AppTheme`)
- Переключение темы (`ThemeNotifier extends ValueNotifier<ThemeMode>`) с персистентностью через `shared_preferences`
- `GlassCard` — glassmorphism-карточка с `BackdropFilter` (dark) / тенью (light), скопирована из `flatter-lab-2`
- `ThemeToggleButton` — кнопка в AppBar для переключения темы, скопирована из `flatter-lab-2`
- CI/CD: GitHub Actions (`release.yml`) — автоматическая сборка подписанного APK и публикация в GitHub Releases при каждом пуше в `main`
- Groovy `android/app/build.gradle` с конфигурацией подписи через `key.properties`

#### Данные и модели
- Модели данных: `Dish`, `Category`, `CartItem`
- `CartNotifier extends ValueNotifier<List<CartItem>>` — управление корзиной в памяти: `addItem`, `removeItem`, `updateQuantity`, `clear`, `totalCount`, `totalPrice`
- `menu_data.dart` — 5 категорий, 26 блюд с названиями, описаниями, ценами, эмодзи и списком ингредиентов:
  - 🥞 Завтраки: 5 блюд (Панкейки, Яичница, Каша, Авокадо-тост, Круассан)
  - 🍜 Супы: 5 блюд (Борщ, Крем-суп из тыквы, Куриный бульон, Грибной суп, Том Ям)
  - ☕ Напитки: 6 блюд (Эспрессо, Капучино, Латте, Матча-латте, Лимонад, Тропический смузи)
  - 🍰 Десерты: 5 блюд (Чизкейк, Брауни, Тирамису, Панна котта, Мороженое)
  - 🍖 Основные блюда: 5 блюд (Стейк Рибай, Карбонара, Лосось, Бургер FlutterCafé, Цыплёнок табака)

#### Экраны

**Уровень 1 (Базовое)** — выполнено:
- Категория «Основные блюда» с 5 блюдами, корректно отображается во всех трёх экранах навигации

**Уровень 2 (Среднее)** — выполнено:
- `CartScreen` — список позиций корзины в `GlassCard`, свайп-удаление (`Dismissible`), счётчик количества (+/−), итоговая сумма, кнопка «Оформить заказ» со SnackBar
- Badge с количеством позиций на иконке вкладки «Корзина» в `BottomNavigationBar`
- Интеграция в `DishDetailScreen` — кнопка «В корзину» с выбором количества и SnackBar-подтверждением

**Уровень 3 (Продвинутое)** — выполнено:
- `CategoriesScreen` — `StatefulWidget` с поиском через `TextField` (в `GlassCard`)
- Фильтрация через `kCategories.expand().where()` по названию и описанию блюда
- При пустом запросе: `SliverGrid` 2×N с градиентными карточками категорий
- При активном поиске: `SliverList` с результатами (`_DishSearchTile`)
- При отсутствии результатов: экран «Ничего не найдено»

**Навигация:**
- 2 вкладки в `BottomNavigationBar` + `IndexedStack`: Меню и Корзина
- «О приложении» — `MaterialPageRoute` из иконки ℹ️ в AppBar (идентично `flatter-lab-2`)
- Push-навигация внутри таба Меню: Категории → Блюда → Детали
- Поиск: результат → Детали блюда
